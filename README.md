# cloud-prediction

The package contains lightweight CSV, Markdown, JSON, and a consistency check script. It does not contain cloud-level research data, event labels, predictions, model weights, or upstream code. The 203-cloud cohort had been used in earlier research; it is not an untouched independent test set. Static cloud classification cutoffs were calculated from all 1013 cloud masks before the 810/203 split, as disclosed in the package README.
